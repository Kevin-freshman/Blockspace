# Polymarket Crypto 小时市场半年回测

> 研究区间：2026-03-10 00:00 UTC 至 2026-09-10 00:00 UTC（右端不含）；前四个月训练，后两个月严格样本外验证。生成时间：2026-09-11T06:07:47.347212+00:00。

## 结论先行

- 训练集选出的规则是：结算前 **30 分钟**、高概率侧至少 **90.00%**。压力成本后训练资金收益率 0.53%，样本外转为负值（-0.83%）；因此应把它视为被样本外否定的规则。

- 高胜率不是安全垫：样本外 749 笔中命中率为 94.66%，但每次平均失败会吞掉约 21.0 次平均成功。
- 成本决定信号是否可交易：本文按当前公开 Crypto taker 费率 7.0%，并把参考价上移 1.0¢ 做不利滑点压力测试；样本外资金收益率为 -0.83%，日块 bootstrap 95% 区间为 -3.30% 至 1.11%。
- 三个币种不是三个独立赌注：同时触发时的单笔 PNL 相关系数为 BTC/ETH 0.47（n=158）, BTC/SOL 0.40（n=143）, ETH/SOL 0.76（n=164）。只比较 BTC 也触发信号的相同 224 个小时、且每小时总名义本金固定为 $1 时，三资产等权的最大回撤为 $7.18，BTC 单资产为 $6.09；简单分散没有消除同方向尾部风险。
- Filter 的榜单纵向数据目前只有 7 个每日富集样本，且均因高频地址活动截断而未满足 `eligible_for_insight`；所以它只用于提出假设，半年市场回测才承担验证，不能把 7 天地址画像写成半年地址因果结论。

## Filter 纵向研究：有用的是风险过滤器，不是跟单名单

可用数据为 2026-09-04 至 2026-09-10，共 7 个每日富集；高成交量亏损/匹配赢家分别覆盖 116/101 个唯一地址，掉榜/留榜对照覆盖 173/90 个。每天有 54–72 个地址的 activity 达到 1,000 条上限，因此正式 Insight 合格日为 0。下列只能称为描述性 Finding。

| 纵向观察 | 7 日方向 | 对策略真正有用的含义 |
|---|---:|---|
| 成交量匹配的亏损者涉及市场更少 | 0 正 / 7 负 / 0 零；中位差 -27.500个市场 | 不要因地址总 PNL 好看而放松单市场/单主题仓位上限；分散必须跨独立驱动因素。 |
| 亏损者的名义成交 HHI 更高 | 6 正 / 1 负 / 0 零；中位差 0.027 HHI | 把地址或策略的 HHI 设为风控输入；但币种标签不同不等于风险独立。 |
| 掉榜者当日成交频率更低 | 0 正 / 7 负 / 0 零；中位差 -35.625 fills/h | 掉榜首先可能是 rolling window 的活动衰减，不应直接解释为新亏损；跟单前要求跨日留榜与持续活跃。 |
| 亏损者的 ≥0.90 BUY 占比反而更低 | 2 正 / 5 负 / 0 零；中位差 -0.014 | 地址 cohort 不支持“亏损来自更多高价 BUY”的原假设；尾盘风险结论必须由独立市场回测给出。 |
| 高频差异不可识别 | 亏损−赢家的频率中位差 7/7 天均为 0 | 两组中位数都撞到 1,000 条/24h 上限（41.67 fills/h）；禁止把 capped 频率当成排序信号。 |

## 交易决策：当前不部署

1. **拒绝训练期参数**：结算前 30 分钟、参考概率 ≥90.00% 的规则样本外为 -0.83%，且置信区间跨 0。
2. **避免超尾盘 taker 扫单**：0.90 门槛在 5m 与 2m 窗口训练/样本外均为负；2m 两段的 95% 日块区间都低于 0。高命中率不足以覆盖极薄利润、费用、滑点和偶发归零。
3. **设置成本闸门**：下单判断必须使用可成交 ask，不使用图表价；允许滑点不得高于下表的样本外 break-even 值，并再留安全边际。若只能 taker 成交，直接跳过边际过薄的信号。
4. **同小时共享风险预算**：BTC / ETH / SOL 同向波动强，同一结算时段合并为一个风险桶；连续亏损不加仓。
5. 若继续研究，只做至少 4 周 paper trading，记录当时 bid/ask、盘口深度、实际 fill、滑点与未成交率；重新积累数据后再设一个从未参与选参的最终验证集。

## 样本与方法

- 固定系列：BTC `10114`、ETH `10117`、SOL `10122`。
- 理论小时×系列数 13248，读取 13217 个已结算二元市场（99.77% coverage）；至少有价格历史的市场 13217 个。各窗口有效观察：60m=13197, 30m=13173, 15m=13186, 5m=13184, 2m=13199。
- 历史价格只取决策时刻或之前的最后一点，绝不向后取价；第一 outcome 的另一侧按 `1-p` 推导。
- 每个信号按 $1 名义买入，兑付为 0/1。压力成本为 `entry = min(reference + 0.01, 0.9999)`，另计公开 Crypto taker 费公式。
- 参数网格为时间 `{60,30,15,5,2}` 分钟 × 门槛 `{0.80,0.85,0.90,0.95,0.98}`；仅在前四个月且至少 100 笔交易中选资金收益率最高者，后两个月不再调参。

## 重要限制

- `prices-history` 是公开历史价格序列，不是当时可成交 ask、盘口深度或成交承诺；1¢ 滑点只是压力参数。
- 另一 outcome 用 `1-p` 推导，会忽略瞬时价差和两侧不同成交时刻；这使结果更适合筛选假设，而非资金曲线承诺。
- 当前公开费率用于统一压力测试，不保证与半年内每个市场当时的实际费率完全一致；未计资金占用、撤单、延迟和税务。
- 只研究三个固定小时系列，不外推到 5m/15m、体育、政治或长周期市场。市场必须有最终 0/1 结果，因此不存在未结算市场的幸存者问题，但无价格历史的市场会降低 coverage。
- 训练集选参仍可能过拟合；样本外只有两个月，bootstrap 只量化日级抽样不确定性，不能覆盖制度/API/费率变化。
