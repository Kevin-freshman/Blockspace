# 课后练习：实现一个 USDT 时间锁托管合约

## 练习目标

本练习要求同学阅读 USDT 的智能合约代码，理解 ERC20 Token 的基本工作逻辑，并使用 Solidity 与 Foundry 实现一个简单的 USDT 时间锁托管合约。

完成后，你应该能够理解：

- ERC20 Token 的余额是如何记录的；
- `transfer`、`approve`、`transferFrom` 的区别；
- 智能合约如何持有 ERC20 Token；
- 如何使用 `block.timestamp` 实现时间限制；
- 如何使用 Foundry 编写智能合约测试。

## 任务二：实现 USDT 时间锁托管合约

请编写一个 Solidity 智能合约，实现以下功能：

- 合约名称建议为：**`USDTTimeLock`**

### 功能要求

- 用户可以将一定数量的 USDT 存入合约；
- 存入时，合约记录：
  - 存款人地址；
  - 存款金额；
  - 存款时间；
  - 可取回时间；
- 用户存入 USDT 后，必须等待至少 **1 天**才能取回；
- 只有存款人本人可以取回自己的 USDT；
- 未到 1 天时，用户不能取回；
- 成功取回后，合约应清除该用户的存款记录，防止重复取款。

### 参考接口

```solidity
interface IERC20 {
    function transfer(address to, uint256 amount) external returns (bool);

    function transferFrom(address from, address to, uint256 amount) external
        returns (bool);

    function balanceOf(address account) external view returns (uint256);
}
```

### 核心函数建议

```solidity
function deposit(uint256 amount) external;

function withdraw() external;

function getDeposit(address user) external view returns (...);
```

### 注意

用户调用 `deposit` 前，需要先对你的合约调用 USDT 的 `approve`，否则 `transferFrom` 会失败。

请使用 Foundry 为上述合约编写测试，至少覆盖以下场景：

- 用户成功存入 USDT；

- 取回后，用户的存款记录被清除；
- 非本人不能取走其他用户的 USDT。

### 建议测试流程

```solidity

function testCannotWithdrawBeforeOneDay() public;
```
